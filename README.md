# Математическое программирование

Лабораторные работы по предмету "Математическое программирование". Язык C++.

## Что внутри

- Laboratory_1 — Laboratory_6 — лабораторные работы на C++
- task3 — задание к лабораторной 1
- лабы — задания к лабораторным
- лекции — методички и презентации

## Про работы

Задачи математического программирования: метод ветвей и границ, работа с графами, расстояние Левенштейна и другие. Реализация на C++ в Visual Studio.
